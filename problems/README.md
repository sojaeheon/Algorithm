# Problems

문제 풀이 코드를 플랫폼별로 저장합니다.

## 폴더

| 폴더 | 내용 |
| --- | --- |
| `jungol` | JUNGOL 문제 풀이 |
| `review` | 다시 풀 문제, 틀린 문제, 헷갈린 문제 |

## 파일 이름

```text
문제번호_문제이름.py
```

예시:

```text
1880_password.py
```

## 풀이 파일 상단 템플릿

```python
# JUNGOL 0000 문제이름
# 분류:
# 핵심:
# 시간 복잡도:
```

## 풀이 기록 기준

- 처음 맞힌 문제는 플랫폼 폴더에 저장한다.
- 다시 풀어야 할 문제는 `review`에도 기록한다.
- 풀이 파일 상단에 핵심 아이디어를 한두 줄로 남긴다.
- 관련 알고리즘 문서가 있으면 해당 문서의 관련 문제 표에도 추가한다.
