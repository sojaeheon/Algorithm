# JUNGOL

JUNGOL 문제 풀이를 저장하는 폴더입니다.

## 파일 이름 규칙

```text
문제번호_문제이름.py
```

예시:

```text
1880_password.py
```

문제 이름이 길거나 한글이면 짧은 영어 이름으로 바꿔도 됩니다.

```text
1234_stack.py
1234_bfs.py
```

## 풀이 파일 템플릿

```python
# JUNGOL 0000 문제이름
# 분류:
# 핵심:
# 시간 복잡도:

import sys
input = sys.stdin.readline
```
