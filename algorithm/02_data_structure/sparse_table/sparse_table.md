# Sparse Table

Sparse Table은 값이 바뀌지 않는 배열에서 구간 질의를 매우 빠르게 처리하기 위한 전처리 기법이다.

대표적으로 구간 최솟값, 구간 최댓값, GCD 질의에 사용한다.

## 1. 언제 쓰는가

- 배열 값이 중간에 바뀌지 않는다.
- 구간 최솟값, 최댓값, GCD를 여러 번 구해야 한다.
- 질의가 매우 많다.
- 전처리에 시간을 쓰고 질의를 빠르게 처리하고 싶다.
- LCA 전처리처럼 `2^k` 단위 정보가 필요하다.

## 2. 핵심 아이디어

길이가 `2^k`인 구간의 답을 미리 저장한다.

```text
table[k][i] = i에서 시작하는 길이 2^k 구간의 답
```

예:

```text
table[0][i] = 길이 1 구간
table[1][i] = 길이 2 구간
table[2][i] = 길이 4 구간
```

## 3. RMQ 전처리

구간 최솟값을 구하는 Sparse Table이다.

```python
n = len(arr)
log = n.bit_length()

table = [[0] * n for _ in range(log)]
table[0] = arr[:]

for k in range(1, log):
    length = 1 << k
    half = length >> 1

    for i in range(n - length + 1):
        table[k][i] = min(table[k - 1][i], table[k - 1][i + half])
```

## 4. 구간 질의

구간 `[left, right]`의 길이에 맞는 가장 큰 `2^k`를 고른다.

```python
def query(left, right):
    length = right - left + 1
    k = length.bit_length() - 1

    return min(
        table[k][left],
        table[k][right - (1 << k) + 1],
    )
```

최솟값처럼 구간이 겹쳐도 문제가 없는 연산은 두 구간으로 답을 구할 수 있다.

## 5. 왜 두 구간으로 되는가

예를 들어 길이 10인 구간을 질의한다고 하자.

가장 큰 `2^k`는 8이다.

```text
[left, left + 7]
[right - 7, right]
```

두 구간이 겹칠 수 있지만, 최솟값은 중복해서 보아도 결과가 바뀌지 않는다.

## 6. 사용할 수 있는 연산

Sparse Table의 `O(1)` 질의는 겹쳐도 결과가 변하지 않는 연산에 적합하다.

사용하기 좋음:

- 최솟값
- 최댓값
- GCD

주의 필요:

- 합
- 곱

구간 합은 겹치면 값이 중복되므로 이 방식으로 바로 처리할 수 없다.

## 7. 복잡도

| 작업 | 복잡도 |
| --- | --- |
| 전처리 | `O(N log N)` |
| 질의 | `O(1)` |
| 갱신 | 불가능하거나 비효율적 |

## 8. 세그먼트 트리와 비교

| 구분 | Sparse Table | Segment Tree |
| --- | --- | --- |
| 값 갱신 | 어려움 | 가능 |
| 전처리 | `O(N log N)` | `O(N)` |
| 질의 | `O(1)` | `O(log N)` |
| 대표 사용 | 정적 RMQ | 동적 구간 질의 |

## 9. 자주 하는 실수

### 값이 바뀌는 문제에 사용

Sparse Table은 기본적으로 정적 배열용이다. 값이 바뀌면 세그먼트 트리를 고려한다.

### 합 질의에 그대로 사용

최솟값/최댓값과 달리 합은 겹치는 구간을 중복 계산하면 안 된다.

### 인덱스 범위

`right - (1 << k) + 1`이 두 번째 구간의 시작점이다.

## 10. 정리

Sparse Table은 값이 변하지 않는 배열에서 구간 최솟값, 최댓값, GCD를 빠르게 처리하는 전처리 기법이다. 질의가 많고 갱신이 없다면 세그먼트 트리보다 간단하고 빠를 수 있다.
