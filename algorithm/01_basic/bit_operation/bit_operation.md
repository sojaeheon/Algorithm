# Bit Operation

비트 연산은 정수를 2진수로 보고 각 자리의 0과 1을 다루는 방법이다. 부분집합, 방문 상태, 플래그 관리, 비트마스크 DP에 자주 사용된다.

## 1. 기본 연산

| 연산 | 의미 | 예시 |
| --- | --- | --- |
| `&` | 둘 다 1이면 1 | `a & b` |
| `|` | 하나라도 1이면 1 | `a | b` |
| `^` | 서로 다르면 1 | `a ^ b` |
| `~` | 비트 반전 | `~a` |
| `<<` | 왼쪽 이동 | `1 << k` |
| `>>` | 오른쪽 이동 | `x >> k` |

## 2. k번째 비트 확인

```python
if mask & (1 << k):
    print("on")
```

## 3. k번째 비트 켜기

```python
mask |= (1 << k)
```

## 4. k번째 비트 끄기

```python
mask &= ~(1 << k)
```

## 5. k번째 비트 토글

```python
mask ^= (1 << k)
```

## 6. 부분집합 순회

```python
n = 4

for mask in range(1 << n):
    selected = []

    for i in range(n):
        if mask & (1 << i):
            selected.append(i)
```

`1 << n`은 `2^n`을 의미한다.

## 7. 비트 개수 세기

```python
count = mask.bit_count()
```

선택된 원소 개수를 확인할 때 유용하다.

## 8. 짝수/홀수 확인

```python
if x & 1:
    print("odd")
else:
    print("even")
```

## 9. 자주 쓰는 패턴

### 방문 추가

```python
visited = visited | (1 << nxt)
```

### 이미 방문했는지 확인

```python
if visited & (1 << nxt):
    continue
```

### 전체 방문 상태

```python
full = (1 << n) - 1
```

`n`개의 비트가 모두 1인 상태이다.

## 10. 자주 하는 실수

### 연산자 우선순위

괄호를 넣는 습관이 안전하다.

```python
mask & (1 << i)
```

### N이 너무 큰 경우

비트마스크는 상태 수가 `2^N`이므로 `N`이 커지면 사용할 수 없다.

### 0번째 비트 기준

대부분의 구현은 0번째 원소를 0번째 비트에 대응시킨다.

## 11. 정리

비트 연산은 선택 여부를 정수 하나로 압축해서 표현하는 방법이다. 부분집합과 비트마스크 DP를 이해하기 위한 기본 도구이다.
