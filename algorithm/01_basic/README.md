## 문제를 풀 때 확인할 것

- 입력 크기상 `O(N^2)`이 가능한가?
- 정렬하면 문제가 쉬워지는가?
- 답을 정해놓고 가능 여부를 검사할 수 있는가?
- 재귀의 기저 조건과 상태 변화가 명확한가?
- 선택 여부를 비트마스크로 표현할 수 있는가?
