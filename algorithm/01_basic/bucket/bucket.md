# Bucket

버킷은 값을 여러 구간이나 그룹으로 나누어 처리하는 기법이다. 대표적으로 버킷 정렬, 카운팅 정렬, 빈도 배열이 있다.

## 1. 언제 쓰는가

- 값의 범위가 작다.
- 값을 구간별로 나누어 처리할 수 있다.
- 빈도 개수를 세면 정렬이나 답 계산이 쉬워진다.
- 일반 정렬 `O(N log N)`보다 빠르게 처리하고 싶다.

## 2. 카운팅 정렬

값의 범위가 작을 때 사용할 수 있다.

```python
arr = [3, 1, 2, 3, 2, 1]
max_value = max(arr)

count = [0] * (max_value + 1)

for x in arr:
    count[x] += 1

result = []

for value in range(max_value + 1):
    for _ in range(count[value]):
        result.append(value)
```

## 3. 빈도 배열

값이 몇 번 나왔는지만 필요하면 정렬하지 않고 빈도만 저장한다.

```python
count = [0] * 101

for score in scores:
    count[score] += 1
```

## 4. 버킷 나누기

값을 일정한 구간으로 나누어 저장할 수 있다.

```python
bucket_size = 10
buckets = [[] for _ in range(10)]

for x in arr:
    idx = x // bucket_size
    buckets[idx].append(x)
```

## 5. 좌표 범위 주의

값의 범위가 너무 크면 빈도 배열을 만들 수 없다.

```text
N은 100000인데 값이 10^9까지 가능하면 count 배열은 부적절
```

이 경우 해시, 정렬, 좌표 압축을 고려한다.

## 6. 복잡도

카운팅 정렬은 값의 최댓값을 `K`라고 하면 `O(N + K)`이다.

`K`가 작으면 빠르지만, `K`가 너무 크면 메모리와 시간이 낭비된다.

## 7. 자주 하는 실수

- 값의 범위를 확인하지 않고 큰 배열을 만드는 경우
- 음수 값이 있는데 그대로 인덱스로 쓰는 경우
- 안정 정렬이 필요한 문제에서 단순 빈도만 사용하는 경우

## 8. 정리

버킷 계열 기법은 값의 범위가 작거나 구간화할 수 있을 때 강력하다. 핵심은 `N`뿐 아니라 값의 범위 `K`도 함께 확인하는 것이다.
