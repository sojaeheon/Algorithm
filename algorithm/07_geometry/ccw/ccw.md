# CCW

CCW는 세 점의 방향을 판단하는 기하 알고리즘이다. 세 점이 반시계 방향인지, 시계 방향인지, 일직선인지 알 수 있다.

## 1. 공식

점 `A(x1, y1)`, `B(x2, y2)`, `C(x3, y3)`가 있을 때:

```python
def ccw(a, b, c):
    value = (b[0] - a[0]) * (c[1] - a[1]) - (b[1] - a[1]) * (c[0] - a[0])

    if value > 0:
        return 1
    if value < 0:
        return -1
    return 0
```

## 2. 반환값 의미

| 반환값 | 의미 |
| --- | --- |
| `1` | 반시계 방향 |
| `-1` | 시계 방향 |
| `0` | 일직선 |

## 3. 벡터 외적 관점

CCW는 벡터 `AB`와 `AC`의 외적 부호를 이용한다.

```text
AB = B - A
AC = C - A
cross = AB.x * AC.y - AB.y * AC.x
```

외적이 양수이면 C가 AB의 왼쪽에 있고, 음수이면 오른쪽에 있다.

## 4. 언제 쓰는가

- 세 점의 방향 판단
- 선분 교차
- 다각형 방향 확인
- 볼록 껍질
- 각도 정렬

## 5. 선분 교차 기본

두 선분 `AB`, `CD`가 교차하는지 확인할 때 CCW를 사용한다.

```python
def intersect(a, b, c, d):
    ab = ccw(a, b, c) * ccw(a, b, d)
    cd = ccw(c, d, a) * ccw(c, d, b)

    if ab == 0 and cd == 0:
        if a > b:
            a, b = b, a
        if c > d:
            c, d = d, c
        return c <= b and a <= d

    return ab <= 0 and cd <= 0
```

일직선으로 겹치는 경우를 따로 처리해야 한다.

## 6. 좌표 범위

Python은 정수 크기가 사실상 자유롭기 때문에 큰 좌표 곱셈도 안전하다. C/C++에서는 `long long` 범위를 고려해야 한다.

## 7. 자주 하는 실수

### 점 순서 변경

`ccw(a, b, c)`와 `ccw(a, c, b)`는 부호가 반대가 된다.

### 일직선 처리 누락

`ccw == 0`인 경우가 문제에서 중요할 수 있다. 특히 선분 교차에서 끝점이 닿는 경우를 확인해야 한다.

### float 사용

정수 좌표 문제에서는 가능하면 정수 연산으로 처리한다.

## 8. 정리

CCW는 기하 문제의 기본 도구이다. 세 점의 방향을 외적의 부호로 판단하며, 선분 교차와 볼록 껍질 같은 알고리즘의 기반이 된다.
