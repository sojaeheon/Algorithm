# Tree DP

트리 DP는 트리의 부모-자식 관계를 이용해 서브트리의 답을 계산하고, 그 결과를 부모로 올리는 DP이다.

## 1. 언제 쓰는가

- 입력이 트리이다.
- 각 노드의 선택 여부가 자식이나 부모에 영향을 준다.
- 서브트리의 정보를 모아야 한다.
- 독립 집합, 트리에서의 최댓값/최솟값, 트리 색칠 문제가 나온다.

## 2. 기본 생각

트리는 사이클이 없기 때문에 부모를 정하면 아래에서 위로 정보를 모을 수 있다.

```text
자식들의 답을 먼저 구한다.
자식들의 답을 이용해 현재 노드의 답을 만든다.
```

## 3. 대표 상태

노드를 선택하거나 선택하지 않는 문제가 자주 나온다.

```text
dp[now][0] = now를 선택하지 않았을 때 now의 서브트리에서 얻는 최댓값
dp[now][1] = now를 선택했을 때 now의 서브트리에서 얻는 최댓값
```

## 4. 기본 코드

```python
def dfs(now, parent):
    dp[now][0] = 0
    dp[now][1] = value[now]

    for nxt in tree[now]:
        if nxt == parent:
            continue

        dfs(nxt, now)

        dp[now][0] += max(dp[nxt][0], dp[nxt][1])
        dp[now][1] += dp[nxt][0]
```

## 5. 점화식 의미

현재 노드를 선택하지 않으면 자식은 선택해도 되고 안 해도 된다.

```python
dp[now][0] += max(dp[nxt][0], dp[nxt][1])
```

현재 노드를 선택하면 인접한 자식은 선택할 수 없다.

```python
dp[now][1] += dp[nxt][0]
```

## 6. 정답

루트를 1로 잡았다면:

```python
answer = max(dp[1][0], dp[1][1])
```

루트는 보통 아무 정점으로 잡아도 된다. 트리는 연결되어 있고 사이클이 없기 때문이다.

## 7. 부모 처리

무방향 트리에서는 부모로 다시 올라가면 무한 재귀가 된다.

```python
if nxt == parent:
    continue
```

## 8. 트리 DP와 일반 DFS

트리 DP는 DFS를 하면서 값을 계산한다. 단순 방문이 아니라, 자식의 계산 결과를 부모가 사용한다는 점이 핵심이다.

## 9. 자주 하는 실수

### 부모로 되돌아감

`parent`를 넘겨서 부모 간선을 제외한다.

### dp 초기화 누락

DFS 안에서 현재 노드의 초기값을 먼저 잡는다.

```python
dp[now][0] = 0
dp[now][1] = value[now]
```

### 상태 의미 혼동

`0`과 `1`이 각각 선택/비선택 중 무엇인지 주석으로 적어두면 좋다.

## 10. 정리

트리 DP는 서브트리의 답을 부모로 올려 전체 답을 만드는 방식이다. 핵심은 상태 정의와 부모-자식 관계를 명확히 하는 것이다.
