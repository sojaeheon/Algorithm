# Dynamic Programming

DP(Dynamic Programming)는 큰 문제의 답을 작은 문제의 답으로 만들어내는 방법이다. 같은 계산이 반복되고, 이전 결과를 저장해 재사용할 수 있을 때 사용한다.

## 1. DP를 쓰는 조건

DP는 보통 다음 조건이 있을 때 사용한다.

### 같은 부분 문제가 반복된다

예를 들어 피보나치 수열에서 `fib(5)`를 구할 때 `fib(3)` 같은 값이 여러 번 계산된다.

### 작은 문제의 답으로 큰 문제의 답을 만들 수 있다

```text
dp[i] = dp[i - 1] + dp[i - 2]
```

처럼 이전 상태로 현재 상태를 구할 수 있어야 한다.

## 2. DP 문제를 푸는 순서

1. `dp` 배열의 의미를 정한다.
2. 초기값을 정한다.
3. 점화식을 세운다.
4. 반복 순서를 정한다.
5. 정답이 어디에 있는지 확인한다.

## 3. 가장 중요한 질문

DP를 시작하기 전에 다음 문장을 먼저 써본다.

```text
dp[i]는 무엇을 의미하는가?
```

예시:

```text
dp[i] = i번째까지 봤을 때의 최댓값
dp[i] = i를 마지막으로 하는 경우의 수
dp[i][j] = i번째까지 보고 j 상태일 때의 최적값
```

## 4. 피보나치 예시

```python
n = int(input())
dp = [0] * (n + 1)

if n >= 1:
    dp[1] = 1

for i in range(2, n + 1):
    dp[i] = dp[i - 1] + dp[i - 2]

print(dp[n])
```

의미:

```text
dp[i] = i번째 피보나치 수
```

## 5. Bottom-up

작은 상태부터 차례대로 채우는 방식이다.

```python
dp[0] = 0
dp[1] = 1

for i in range(2, n + 1):
    dp[i] = dp[i - 1] + dp[i - 2]
```

반복문으로 구현해서 재귀 깊이 문제가 없다.

## 6. Top-down과 메모이제이션

재귀로 필요한 상태만 계산하고, 이미 계산한 결과는 저장한다.

```python
memo = [-1] * (n + 1)


def fib(x):
    if x <= 1:
        return x

    if memo[x] != -1:
        return memo[x]

    memo[x] = fib(x - 1) + fib(x - 2)
    return memo[x]
```

## 7. 1차원 DP

```python
dp = [0] * (n + 1)

for i in range(1, n + 1):
    dp[i] = max(dp[i], dp[i - 1] + value[i])
```

대표 유형:

- 계단 오르기
- 포도주 시식
- 1차원 최댓값/최솟값
- LIS 기본형

## 8. 2차원 DP

상태가 두 개 필요하면 2차원 배열을 사용한다.

```python
dp = [[0] * (m + 1) for _ in range(n + 1)]
```

예시:

```text
dp[i][j] = i번째 물건까지 봤고, 무게 j일 때의 최대 가치
```

대표 유형:

- 배낭
- LCS
- 격자 경로
- 구간 DP

## 9. 경우의 수 DP

답이 너무 커지는 문제에서는 나머지 연산이 필요할 수 있다.

```python
MOD = 1_000_000_007

dp[i] = (dp[i - 1] + dp[i - 2]) % MOD
```

문제에서 "1,000,000,007로 나눈 나머지" 같은 표현이 나오면 모든 덧셈과 곱셈마다 나머지를 적용한다.

## 10. 최댓값/최솟값 DP

최댓값을 구할 때는 아주 작은 값으로, 최솟값을 구할 때는 아주 큰 값으로 초기화한다.

```python
INF = 10**18

dp_min = [INF] * (n + 1)
dp_max = [-INF] * (n + 1)
```

## 11. 점화식 세우는 법

현재 상태를 기준으로 생각한다.

```text
dp[i]를 만들기 직전에는 어떤 상태였을까?
```

또는 이전 상태에서 다음 상태로 보내는 방식도 가능하다.

```python
for i in range(n):
    dp[i + 1] = max(dp[i + 1], dp[i] + value)
```

## 12. 반복 순서

DP는 참조하는 값이 먼저 계산되어 있어야 한다.

```python
for i in range(1, n + 1):
    dp[i] = dp[i - 1] + 1
```

배낭처럼 같은 배열을 재사용할 때는 순서가 특히 중요하다.

```python
# 0/1 배낭: 뒤에서 앞으로
for w in range(capacity, weight - 1, -1):
    dp[w] = max(dp[w], dp[w - weight] + value)
```

## 13. DP를 떠올리는 신호

- 경우의 수를 구하라.
- 최댓값 또는 최솟값을 구하라.
- 이전 선택이 다음 선택에 영향을 준다.
- 같은 계산이 반복된다.
- `N`이 크지만 상태 수는 제한적이다.
- 완전 탐색은 느린데, 중복되는 상태가 많다.

## 14. 자주 하는 실수

### 상태 정의 없이 코드부터 쓰는 경우

먼저 주석으로 의미를 적는다.

```python
# dp[i] = i번째 칸에 도착하는 경우의 수
```

### 초기값 부족

`dp[0]`, `dp[1]` 같은 시작 값을 빠뜨리면 점화식이 맞아도 답이 틀린다.

### 반복 방향 실수

같은 배열을 갱신하는 문제에서는 앞에서부터 돌지, 뒤에서부터 돌지 확인해야 한다.

### 정답 위치 착각

항상 `dp[n]`이 답은 아니다.

```python
answer = max(dp)
```

인 경우도 많다.

## 정리

DP의 핵심은 배열을 만드는 것이 아니라 상태를 정의하는 것이다. `dp[i]`가 무엇인지 정확히 말할 수 있으면, 점화식과 초기값도 훨씬 쉽게 정해진다.
