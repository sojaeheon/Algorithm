# Combinatorics

순열, 조합, 부분집합처럼 가능한 경우를 만드는 기본 패턴을 정리합니다.

## 문서

| 주제 | 문서 | 핵심 |
| --- | --- | --- |
| 순열 | [permutation.md](permutation/permutation.md) | 순서를 고려해서 나열 |
| 조합 | [combination.md](combination/combination.md) | 순서 없이 선택 |
| 부분집합 | [subset.md](subset/subset.md) | 각 원소를 선택하거나 선택하지 않음 |

## 비교

| 구분 | 순서 | 개수 |
| --- | --- | --- |
| 순열 | 중요 | `NPr` |
| 조합 | 중요하지 않음 | `NCr` |
| 부분집합 | 선택 여부만 중요 | `2^N` |
