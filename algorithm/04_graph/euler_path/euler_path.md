# Euler Path

오일러 경로는 그래프의 모든 간선을 정확히 한 번씩 지나는 경로이다. 시작점과 끝점이 같으면 오일러 회로라고 한다.

정점은 여러 번 방문해도 되지만, 간선은 정확히 한 번만 사용해야 한다.

## 1. 언제 쓰는가

- 모든 길이나 간선을 한 번씩 사용해야 한다.
- 단어 체인, 도로 순회, 경로 복원 문제가 나온다.
- 정점 방문보다 간선 사용 여부가 중요하다.
- 오일러 경로 또는 오일러 회로 존재 여부를 판단해야 한다.

## 2. 무방향 그래프 조건

간선이 있는 정점들이 하나의 연결 요소에 있어야 한다.

| 종류 | 조건 |
| --- | --- |
| 오일러 회로 | 모든 정점의 차수가 짝수 |
| 오일러 경로 | 홀수 차수 정점이 정확히 2개 |

홀수 차수 정점이 0개이면 회로이고, 2개이면 경로이다.

## 3. 방향 그래프 조건

| 종류 | 조건 |
| --- | --- |
| 오일러 회로 | 모든 정점에서 `in == out` |
| 오일러 경로 | 시작점은 `out = in + 1`, 끝점은 `in = out + 1`, 나머지는 `in == out` |

## 4. Hierholzer 알고리즘

오일러 경로를 실제로 구성할 때 사용한다.

```python
def euler(start):
    stack = [start]
    path = []

    while stack:
        now = stack[-1]

        if graph[now]:
            stack.append(graph[now].pop())
        else:
            path.append(stack.pop())

    return path[::-1]
```

위 코드는 간선을 `pop()`하면서 사용한다. 그래프가 변해도 되는 상황에서 사용한다.

## 5. 왜 나중에 path에 넣는가

더 이상 사용할 간선이 없는 정점을 path에 넣는다. 이렇게 하면 막다른 경로부터 쌓이고, 마지막에 뒤집으면 올바른 오일러 경로가 된다.

## 6. 시작점 선택

무방향 그래프:

- 홀수 차수 정점이 2개이면 그중 하나에서 시작
- 홀수 차수 정점이 0개이면 간선이 있는 아무 정점에서 시작

방향 그래프:

- `out = in + 1`인 정점이 있으면 그 정점에서 시작
- 없으면 간선이 있는 아무 정점에서 시작

## 7. 자주 하는 실수

### 정점 방문 체크를 하는 경우

오일러 경로는 정점이 아니라 간선을 한 번씩 사용해야 한다. 정점 방문 체크로 풀면 틀린다.

### 연결성 확인 누락

차수 조건이 맞아도 간선이 있는 정점들이 분리되어 있으면 오일러 경로가 없다.

### graph를 파괴하는 코드

`pop()`으로 간선을 제거하므로 원본 그래프가 필요하면 복사해야 한다.

## 8. 정리

오일러 경로는 모든 간선을 정확히 한 번씩 사용하는 경로이다. 존재 조건은 차수로 판단하고, 실제 경로 구성은 Hierholzer 알고리즘을 사용한다.
