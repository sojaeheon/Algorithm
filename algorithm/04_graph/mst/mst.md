# 신장 트리와 최소 신장 트리

신장 트리(Spanning Tree)는 **연결된 무방향 그래프의 모든 정점을 포함하는 트리**이다.  
최소 신장 트리(MST, Minimum Spanning Tree)는 가능한 신장 트리 중에서 **간선 가중치 합이 최소인 신장 트리**이다.

크루스칼(Kruskal)과 프림(Prim)은 같은 MST를 구하지만 관점이 다르다.

- 크루스칼: 전체 간선 중 가장 싼 간선을 고르되 사이클을 피한다.
- 프림: 하나의 정점에서 시작하여 현재 트리 바깥으로 나가는 가장 싼 간선을 고른다.

---

## 1. 먼저 알아야 할 그래프와 트리 개념

그래프 `G = (V, E)`에서 `V`는 정점 집합, `E`는 간선 집합이다.

### 연결 그래프

임의의 두 정점 사이에 경로가 존재하는 그래프이다. 연결되지 않은 그래프에는 모든 정점을 포함하는 신장 트리가 존재하지 않는다.

### 사이클

한 정점에서 출발하여 간선을 따라 이동한 뒤 다시 그 정점으로 돌아오는 경로이다.

### 트리

연결되어 있으면서 사이클이 없는 무방향 그래프이다. 정점 수가 `V`개인 트리는 다음 성질을 모두 만족한다.

- 간선 수가 정확히 `V - 1`개이다.
- 임의의 두 정점 사이의 단순 경로가 정확히 하나이다.
- 간선 하나를 제거하면 두 컴포넌트로 분리된다.
- 서로 다른 두 정점을 잇는 간선 하나를 추가하면 사이클이 정확히 하나 생긴다.

이 성질들은 서로 독립된 조건이 아니라 트리를 다른 관점에서 표현한 것이다.

---

## 2. 신장 트리(Spanning Tree)

그래프 `G`의 신장 트리 `T`는 다음을 만족하는 부분 그래프이다.

1. 원래 그래프의 모든 정점을 포함한다.
2. 원래 그래프의 간선 일부만 사용한다.
3. 모든 정점이 연결되어 있다.
4. 사이클이 없다.

정점이 `V`개라면 모든 신장 트리는 간선을 정확히 `V - 1`개 가진다.

신장 트리는 하나만 존재할 필요가 없다. 그래프에 간선이 많을수록 여러 신장 트리가 존재할 수 있다. 원래 그래프 자체가 트리라면 신장 트리는 원래 그래프 하나뿐이다.

### 신장 트리가 존재하는 조건

무방향 그래프가 연결되어 있어야 한다. 그래프가 여러 컴포넌트로 나뉘어 있다면 하나의 신장 트리는 만들 수 없고, 각 컴포넌트의 신장 트리를 모은 **신장 포리스트(Spanning Forest)**만 만들 수 있다.

---

## 3. 최소 신장 트리(MST)

가중치가 있는 연결 무방향 그래프에서 신장 트리 `T`의 비용은 다음과 같다.

```text
cost(T) = T에 포함된 모든 간선의 가중치 합
```

이 값이 가능한 모든 신장 트리 중 최소인 것이 MST이다.

### 핵심 특징

- 모든 정점을 연결한다.
- 선택한 간선 수는 `V - 1`개이다.
- 사이클이 없다.
- 전체 간선 비용의 합이 최소이다.
- 간선 가중치가 음수여도 크루스칼과 프림을 사용할 수 있다.
- MST의 총비용은 하나로 결정되지만, 같은 가중치의 간선이 있으면 MST 모양은 여러 개일 수 있다.
- 모든 간선의 가중치가 서로 다르면 MST는 유일하다.

마지막 명제의 역은 항상 참이 아니다. 같은 가중치가 존재해도 MST가 유일할 수 있다.

### MST와 최단 경로의 차이

| 구분 | 최소 신장 트리 | 최단 경로 |
| --- | --- | --- |
| 목적 | 전체 정점을 연결하는 총비용 최소화 | 출발점과 목적지 사이 비용 최소화 |
| 결과 | `V - 1`개의 간선으로 된 트리 | 거리 배열 또는 특정 경로 |
| 대표 알고리즘 | 크루스칼, 프림 | BFS, 다익스트라, 벨만-포드 |
| 중요 관점 | 전체 네트워크의 설치 비용 | 한 지점에서 다른 지점까지 이동 비용 |

MST 안의 두 정점 사이 경로가 원래 그래프에서의 최단 경로라는 보장은 없다.

## 4. MST가 성립하는 핵심 원리

두 성질을 이해하면 크루스칼과 프림이 왜 정답인지 설명할 수 있다.

### 4.1 컷 성질(Cut Property)

컷은 정점 집합을 서로 겹치지 않는 두 집합 `S`와 `V - S`로 나누는 것이다. 두 집합을 가로지르는 간선을 컷을 지나는 간선이라고 한다.

> 어떤 컷을 지나는 간선 중 가중치가 가장 작은 간선은 어떤 MST에 포함될 수 있는 안전한 간선이다.

최솟값이 유일하다면 그 간선은 모든 MST에 포함된다.

#### 직관적인 증명

현재 MST에 그 최소 간선 `e`가 없다고 가정한다. `e`를 MST에 추가하면 사이클이 하나 생긴다. 그 사이클에는 같은 컷을 가로지르는 다른 간선 `f`가 반드시 존재한다. `e`가 컷에서 가장 싸므로 `w(e) <= w(f)`이다. `f`를 제거하고 `e`를 넣으면 여전히 신장 트리이고 비용은 증가하지 않는다. 따라서 `e`를 포함하는 MST가 존재한다.

- 프림은 `방문한 정점 / 방문하지 않은 정점`이라는 컷에서 최소 간선을 고른다.
- 크루스칼은 현재 서로 다른 컴포넌트를 가르는 컷에서 안전한 최소 간선을 고른다.

### 4.2 사이클 성질(Cycle Property)

> 사이클에서 가중치가 유일하게 가장 큰 간선은 어떤 MST에도 포함될 수 없다.

그 간선을 제거해도 사이클의 나머지 간선으로 연결 상태가 유지되며, 더 작은 비용의 트리를 만들 수 있기 때문이다.

크루스칼이 이미 연결된 두 정점을 잇는 간선을 버리는 행동은 사이클을 만들 필요가 없다는 성질과 연결된다.

## 5. 크루스칼 알고리즘

크루스칼은 **간선 중심**의 그리디 알고리즘이다. 처음에는 모든 정점이 서로 다른 컴포넌트에 있다고 생각하고, 가장 싼 간선부터 서로 다른 컴포넌트를 합친다.

### 동작 순서

```text
1. 모든 간선을 가중치 오름차순으로 정렬한다.
2. 가장 싼 간선부터 하나씩 확인한다.
3. 양 끝 정점이 이미 같은 집합이면 사이클이 생기므로 버린다.
4. 서로 다른 집합이면 간선을 선택하고 두 집합을 합친다.
5. 간선을 V - 1개 선택하면 종료한다.
6. 끝까지 선택한 간선이 V - 1개보다 적으면 그래프가 연결되어 있지 않다.
```

### Union-Find가 필요한 이유

새 간선 `(u, v)`를 추가했을 때 사이클이 생기는지는 `u`와 `v`가 이미 연결되어 있는지로 판단할 수 있다.

- `find(u) == find(v)`: 이미 같은 컴포넌트이므로 추가하면 사이클
- `find(u) != find(v)`: 서로 다른 컴포넌트이므로 안전하게 연결 가능

경로 압축과 union by size/rank를 적용하면 각 연산은 평균적으로 거의 상수 시간이다.

### 완성형 Python 구현

입력 간선은 `(가중치, 정점1, 정점2)` 형태라고 가정한다.

```python
def kruskal(n, edges):
    """정점이 1..n일 때 (MST 비용, 선택한 간선 목록)을 반환한다.
    연결 그래프가 아니면 (None, [])을 반환한다.
    """
    parent = list(range(n + 1))
    size = [1] * (n + 1)

    def find(x):
        while x != parent[x]:
            parent[x] = parent[parent[x]]  # 경로 압축(path halving)
            x = parent[x]
        return x

    def union(a, b):
        root_a = find(a)
        root_b = find(b)

        if root_a == root_b:
            return False

        # 작은 트리를 큰 트리 아래에 붙인다.
        if size[root_a] < size[root_b]:
            root_a, root_b = root_b, root_a

        parent[root_b] = root_a
        size[root_a] += size[root_b]
        return True

    total = 0
    selected = []

    for cost, u, v in sorted(edges):
        if union(u, v):
            total += cost
            selected.append((u, v, cost))

            if len(selected) == n - 1:
                break

    if len(selected) != n - 1:
        return None, []

    return total, selected
```

### 정확성 요약

가중치가 작은 순서대로 보는 현재 간선이 서로 다른 두 컴포넌트를 잇는다면, 그 두 컴포넌트를 가르는 컷에서 아직 선택 가능한 최소 간선이다. 컷 성질에 따라 이 간선은 안전하다. 같은 컴포넌트의 두 정점을 잇는 간선은 사이클을 만들므로 버려도 된다. 이 과정을 `V - 1`번 성공하면 MST가 완성된다.

### 시간·공간 복잡도

- 간선 정렬: `O(E log E)`
- Union-Find 전체: `O(E α(V))`
- 총 시간: `O(E log E)`
- 추가 공간: `O(V)` (간선 저장 공간 제외)

`α(V)`는 역 아커만 함수로, 현실적인 입력 크기에서는 거의 상수이다. 단순 무방향 그래프에서 `E <= V²`이므로 `log E = O(log V)`라고 표현하기도 한다.

## 6. 프림 알고리즘

프림은 **정점과 현재 트리 중심**의 그리디 알고리즘이다. 임의의 한 정점에서 시작하여 현재 트리에 연결된 간선 중 바깥 정점으로 가는 가장 싼 간선을 계속 선택한다.

시작 정점에 따라 선택 순서는 달라질 수 있지만, 최종 MST 비용은 달라지지 않는다.

### 동작 순서

```text
1. 임의의 시작 정점을 우선순위 큐에 비용 0으로 넣는다.
2. 큐에서 비용이 가장 작은 후보를 꺼낸다.
3. 해당 정점을 이미 방문했다면 버린다.
4. 미방문 정점이면 MST에 포함하고 간선 비용을 더한다.
5. 그 정점과 인접한 미방문 정점으로 가는 간선을 큐에 넣는다.
6. 모든 정점을 방문할 때까지 반복한다.
7. 방문하지 못한 정점이 있으면 그래프가 연결되어 있지 않다.
```

힙의 `(0, start, 0)`은 실제 간선이 아니라 시작 정점을 선택하기 위한 가상의 간선이다. 따라서 MST 간선 목록에는 넣지 않는다.

### 완성형 Python 구현: 인접 리스트 + 힙

```python
import heapq


def prim(n, graph, start=1):
    """graph[u]의 원소가 (비용, 이웃)일 때
    (MST 비용, 선택한 간선 목록)을 반환한다.
    연결 그래프가 아니면 (None, [])을 반환한다.
    """
    visited = [False] * (n + 1)
    heap = [(0, start, 0)]  # (비용, 현재 정점, 이전 정점)
    total = 0
    selected = []
    visited_count = 0

    while heap and visited_count < n:
        cost, u, prev = heapq.heappop(heap)

        if visited[u]:
            continue

        visited[u] = True
        visited_count += 1
        total += cost

        if prev != 0:
            selected.append((prev, u, cost))

        for next_cost, v in graph[u]:
            if not visited[v]:
                heapq.heappush(heap, (next_cost, v, u))

    if visited_count != n:
        return None, []

    return total, selected
```

인접 리스트는 무방향 간선을 양쪽에 넣어 만든다.

```python
graph = [[] for _ in range(n + 1)]

for cost, u, v in edges:
    graph[u].append((cost, v))
    graph[v].append((cost, u))
```

### 중복 후보를 큐에 넣어도 되는 이유

한 정점으로 향하는 여러 간선이 힙에 동시에 들어갈 수 있다. 가장 싼 후보가 먼저 꺼내져 그 정점이 선택되면, 나중에 꺼낸 나머지 후보는 `visited[u]` 검사에서 버려진다. 이를 흔히 lazy deletion이라고 한다.

### 정확성 요약

매 단계에서 방문 정점 집합 `S`와 미방문 정점 집합 `V - S`가 하나의 컷을 만든다. 프림은 이 컷을 가로지르는 최소 가중치 간선을 선택한다. 컷 성질에 의해 매 선택은 안전하며, 모든 정점을 방문하면 MST가 완성된다.

### 시간·공간 복잡도

인접 리스트와 이진 힙을 사용하면:

- 각 간선이 힙에 들어가고 나오는 비용: `O(E log E)`
- 일반적으로 쓰는 표기: `O(E log V)`
- 공간: `O(V + E)`

두 표기는 단순 그래프에서 점근적으로 같은 범주로 볼 수 있다.

### 밀집 그래프용 `O(V²)` 프림

인접 행렬을 사용하고 매번 방문하지 않은 정점 중 최소 연결 비용을 선형 탐색하면 `O(V²)`이다. 간선이 `V²`에 가깝게 많은 밀집 그래프에서는 힙 구현보다 단순하고 유리할 수 있다.

```python
def prim_dense(matrix):
    n = len(matrix)
    INF = float("inf")
    min_cost = [INF] * n
    visited = [False] * n
    min_cost[0] = 0
    total = 0

    for _ in range(n):
        u = -1

        for v in range(n):
            if not visited[v] and (u == -1 or min_cost[v] < min_cost[u]):
                u = v

        if u == -1 or min_cost[u] == INF:
            return None

        visited[u] = True
        total += min_cost[u]

        for v in range(n):
            if not visited[v]:
                min_cost[v] = min(min_cost[v], matrix[u][v])

    return total
```

간선이 없는 두 정점 사이의 행렬 값은 `INF`, 대각선은 `0`으로 둔다.

## 7. 단계별 예시

다음 무방향 가중치 그래프를 생각하자.

```text
정점: A, B, C, D, E

간선:
A-B(1), A-C(3), B-C(2), B-D(4),
C-D(5), C-E(6), D-E(7)
```

### 크루스칼의 선택

가중치 순으로 정렬하면:

```text
A-B(1), B-C(2), A-C(3), B-D(4),
C-D(5), C-E(6), D-E(7)
```

| 순서 | 확인한 간선 | 판단 | 현재 선택 |
| --- | --- | --- | --- |
| 1 | A-B(1) | 서로 다른 집합 | 선택 |
| 2 | B-C(2) | 서로 다른 집합 | 선택 |
| 3 | A-C(3) | 이미 같은 집합, 사이클 발생 | 제외 |
| 4 | B-D(4) | 서로 다른 집합 | 선택 |
| 5 | C-D(5) | 이미 같은 집합 | 제외 |
| 6 | C-E(6) | 서로 다른 집합 | 선택 후 종료 |

선택 간선은 `A-B, B-C, B-D, C-E`, 총비용은 `1 + 2 + 4 + 6 = 13`이다.

### 프림의 선택

`A`에서 시작하면:

| 단계 | 방문 집합 | 선택한 간선 |
| --- | --- | --- |
| 시작 | `{A}` | 시작 비용 0 |
| 1 | `{A, B}` | A-B(1) |
| 2 | `{A, B, C}` | B-C(2) |
| 3 | `{A, B, C, D}` | B-D(4) |
| 4 | `{A, B, C, D, E}` | C-E(6) |

역시 총비용은 `13`이다.

---

## 8. 크루스칼과 프림 비교

| 구분 | 크루스칼 | 프림 |
| --- | --- | --- |
| 관점 | 전체 간선 중심 | 현재 트리와 인접 간선 중심 |
| 그리디 선택 | 사이클을 만들지 않는 전역 최소 간선 | 방문 집합 밖으로 나가는 최소 간선 |
| 핵심 자료구조 | 정렬 + Union-Find | 인접 리스트 + 최소 힙 |
| 대표 복잡도 | `O(E log E)` | `O(E log V)` |
| 입력 형태 | 간선 목록에 자연스러움 | 인접 리스트에 자연스러움 |
| 희소 그래프 | 적합 | 적합 |
| 밀집 그래프 | 모든 간선 정렬 부담 | 인접 행렬 `O(V²)` 구현 가능 |
| 연결성 확인 | 선택 간선 수가 `V - 1`인지 | 방문 정점 수가 `V`인지 |
| 시작 정점 | 필요 없음 | 임의의 시작 정점 필요 |

### 실전 선택 기준

- 간선 목록이 그대로 주어지고 Union-Find가 익숙하다: 크루스칼
- 인접 리스트가 이미 있고 한 정점에서 확장하는 방식이 자연스럽다: 프림
- 그래프가 매우 밀집되어 인접 행렬을 쓰기 좋다: `O(V²)` 프림 고려
- 간선을 비용순으로 정렬하기 어려운 형태다: 프림 고려

둘 다 충분히 빠른 경우에는 더 실수 없이 구현할 수 있는 알고리즘을 선택하면 된다.

## 9. 최소 신장 포리스트

연결되지 않은 그래프에서 크루스칼을 끝까지 수행하면 각 연결 컴포넌트마다 MST가 만들어진다. 이를 **최소 신장 포리스트(Minimum Spanning Forest)**라고 한다.

프림으로 같은 결과를 얻으려면 모든 미방문 정점을 확인하면서 각 컴포넌트마다 프림을 새로 시작해야 한다.

문제가 “MST 비용”을 요구한다면 연결되지 않은 경우를 실패로 처리해야 하는지, 포리스트 비용을 요구하는지 문제 조건을 반드시 확인한다.

---

## 10. 자주 하는 실수

### 10.1 방향 그래프에 그대로 적용

일반적인 MST는 **무방향 그래프**의 개념이다. 방향 그래프에서 모든 정점을 잇는 최소 구조는 최소 스패닝 아보레선스와 같은 다른 문제이며 크루스칼/프림으로 풀 수 없다.

### 10.2 그래프의 연결성을 확인하지 않음

크루스칼은 `V - 1`개를 골랐는지, 프림은 `V`개 정점을 방문했는지 확인해야 한다.

### 10.3 프림에서 무방향 간선을 한쪽에만 저장

```python
graph[u].append((cost, v))
graph[v].append((cost, u))
```

양방향 모두 저장해야 한다.

### 10.4 프림에서 이미 방문한 정점의 비용을 다시 더함

힙에서는 같은 정점이 여러 번 나올 수 있다. `visited` 검사 뒤에만 비용을 더해야 한다.

```python
cost, u, prev = heapq.heappop(heap)
if visited[u]:
    continue
visited[u] = True
total += cost
```

### 10.5 크루스칼에서 원래 정점 번호만 비교

`u == v`가 아니라 대표가 같은지 확인해야 한다.

```python
if find(u) != find(v):
    union(u, v)
```

### 10.6 간선 튜플의 정렬 순서를 혼동

Python에서 `(cost, u, v)`를 정렬하면 비용이 먼저 비교된다. 입력을 `(u, v, cost)`로 저장했다면 반드시 `key`를 지정한다.

```python
edges.sort(key=lambda edge: edge[2])
```

### 10.7 정점이 0번부터인지 1번부터인지 혼동

배열 크기와 반복 범위를 입력 번호 체계에 맞춰야 한다. 이 문서의 기본 구현은 정점이 `1..n`이라고 가정한다.

### 10.8 가중치가 같은 간선을 잘못 제외

같은 가중치의 간선도 선택될 수 있다. 가중치가 같다는 이유가 아니라 **사이클을 만드는지**로 판단한다.

---

## 11. 문제를 보고 MST임을 알아채는 표현

다음 조건이 함께 나타나면 MST를 의심한다.

- 모든 도시, 컴퓨터, 섬, 정점을 연결해야 한다.
- 도로, 케이블, 파이프 설치 비용의 총합을 최소화한다.
- 두 지점 사이 이동 거리보다 전체 네트워크 구축 비용이 중요하다.
- 이미 연결된 지점끼리는 간접 연결도 허용한다.
- 결과가 사이클을 가질 필요가 없다.

반대로 “특정 출발점에서 모든 정점까지의 최소 거리”라면 다익스트라 같은 최단 경로 문제일 가능성이 높다.

## 12. 응용 유형

### 절약할 수 있는 최대 비용

모든 간선을 유지하는 비용에서 MST 비용을 뺀다.

```text
절약 비용 = 전체 간선 비용 합 - MST 비용
```

### 정점을 두 마을로 분리

MST를 만든 뒤 선택된 간선 중 가장 비싼 하나를 제거하면 두 연결 컴포넌트로 나뉘며, 일반적인 조건에서 두 마을의 유지 비용 합이 최소가 된다.

크루스칼에서는 `V - 2`개의 간선만 선택하고 종료해도 된다.

### 이미 연결된 정점

이미 무료로 연결된 정점끼리 먼저 `union`한 뒤 나머지 간선에 크루스칼을 수행할 수 있다.

### 좌표로 주어진 정점

두 점 사이 비용을 계산해 간선을 만든 뒤 MST를 구할 수 있다. 다만 정점 수가 크면 모든 쌍 `O(V²)`의 간선을 만드는 것 자체가 병목일 수 있으므로 문제의 기하학적 성질을 활용해 후보 간선을 줄여야 할 수 있다.

### 최대 신장 트리

총 가중치를 최대로 만드는 신장 트리가 필요하면 크루스칼의 간선을 내림차순으로 정렬하거나, 프림에서 최대 힙에 해당하는 구조를 사용한다.

## 13. 빠른 복습

```text
신장 트리
└─ 모든 정점을 포함하며 연결되고 사이클이 없는 부분 그래프
   └─ 정점 V개이면 간선 V-1개

최소 신장 트리(MST)
└─ 신장 트리 중 간선 가중치 합이 최소
   ├─ 크루스칼: 간선 정렬 + Union-Find
   │  └─ 다른 컴포넌트를 잇는 가장 싼 간선을 선택
   └─ 프림: 인접 리스트 + 최소 힙
      └─ 현재 트리 밖으로 나가는 가장 싼 간선을 선택
```

### 암기 포인트

- **전체를 최소 비용으로 연결**하면 MST를 떠올린다.
- 크루스칼은 사이클을 Union-Find로 검사한다.
- 프림은 방문 집합과 미방문 집합 사이의 최소 간선을 힙으로 고른다.
- 둘의 정당성은 컷 성질로 설명할 수 있다.
- 연결되지 않은 그래프에는 하나의 MST가 존재하지 않는다.
- MST 안의 경로가 원래 그래프의 최단 경로인 것은 아니다.
